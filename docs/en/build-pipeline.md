# Build and packaging pipeline

Everything revolves around `build.py`: the **same 5 commands** on Linux, macOS and Windows, used both by developers and by the CI (`.github/workflows/release.yml`).

```
python build.py bootstrap      creates the venv and installs dependencies (pinned requirements.txt)
python build.py build-engine   compiles whisper.cpp (per-OS backend) and downloads static ffmpeg/ffprobe
python build.py build          packages the app with PyInstaller (onedir) into dist/WhisperGUI
python build.py package        produces the OS artifact: AppImage / .dmg / NSIS setup.exe
python build.py install        installs the freshly built app locally
```

Flags: `--skip-engine` (reuse the binaries already in `bin/`, with a defensive `ensure_ffmpeg()` call), `--no-bootstrap` (use the current interpreter instead of the venv).

## Constants and platform (build.py:26-42)

- `APP_NAME = "WhisperGUI"`, `EXEC_NAME = "whisper-gui"`, `VERSION = "1.0.0"`, `WHISPERCPP_TAG = "v1.9.1"`, repo `ggml-org/whisper.cpp`.
- Paths: `bin/` (engine + ffmpeg binaries), `dist/` (PyInstaller bundle), `build/cache/` (downloads: ffmpeg, appimagetool, NSIS).
- `IS_WINDOWS / IS_MACOS / IS_LINUX` drive the backend, binary names and separators.

## `bootstrap` (build.py:82)

Creates `.venv` if missing (`python -m venv`) and installs the pinned `requirements.txt` (PyQt6 6.11.0, yt-dlp, platformdirs 4.11.0, pyinstaller 6.21.0). In CI the venv is recreated on every run (setup-python's pip cache speeds it up).

## `build-engine` (build.py:103)

1. `ensure_whispercpp_source()` (build.py:93): clones `external/whisper.cpp` (tag v1.9.1, depth 1) **only if absent** — in CI this path is cached via `--skip-engine`.
2. CMake configuration with the per-OS backend (build.py:113-120):
   - Linux/Windows: `-DGGML_VULKAN=ON -DGGML_AVX512=OFF`;
   - macOS: `-DGGML_METAL=ON -DWHISPER_COREML=ON` (arm64-only).
3. `cmake --build build -j N` with optional `BUILD_JOBS` from the env (default: all cores; on the CI runner = 4 vCPUs).
4. Copies `whisper-cli` into `bin/`.
5. `ensure_ffmpeg()` (build.py:138): downloads static ffmpeg/ffprobe into `build/cache` (`download()` skips if present) and extracts them into `bin/` — johnvansickle (Linux), osxexperts arm64 (macOS), BtbN (Windows).

## `build` (build.py:~190)

PyInstaller `--onedir --noconfirm` with:
- `--add-data <absolute path>:<dest>` for `bin`, `media`, `icon` (absolute paths are mandatory — a paid CI gotcha);
- `--workpath`/`--specpath` under `build/pyinstaller/`;
- output in `dist/WhisperGUI`.

## `package` (build.py:346)

| OS | Function | Artifact | Details |
|---|---|---|---|
| Linux | `package_linux` (build.py:224) | `installer/linux/output/WhisperGUI-x86_64.AppImage` | copies `dist` into `build/AppDir`, generates the PNG icon via `scripts/icon_gen.py` (PyQt6.QtSvg, no external deps), creates `AppRun`/`.desktop`, runs `appimagetool --appimage-extract-and-run` (no FUSE: works in containers and runners). |
| macOS | `package_macos` (build.py:266) | `installer/macos/output/WhisperGUI-macOS-arm64.dmg` | builds `build/WhisperGUI.app` (Contents/MacOS+Resources), generates the ICNS iconset with icon_gen, ad-hoc signs, `hdiutil create` (UDZO). No bundle codesign (useless without notarization). |
| Windows | `package_windows` (build.py:320) | `installer/windows/output/WhisperGUI-x86_64-setup.exe` | looks for `makensis.exe` (PATH or downloads NSIS 3.12 into `build/cache` — the zip has `nsis-3.12/` at its root: recursive search), compiles `installer/windows/whispergui.nsi` with `-DVERSION -DAPP_PATH -DOUT_FILE`. |

## `install` (build.py:355)

| OS | Destination |
|---|---|
| Linux | `~/.local/lib/whisper-gui` (bundle) + `~/.local/bin/whisper-gui` launcher + SVG icon and `.desktop` in `~/.local/share` (application menu entry) |
| macOS | `~/Applications/WhisperGUI.app` |
| Windows | generated by the NSIS setup (in `%LOCALAPPDATA%`, no admin) |

## Wrappers and related scripts

- `install.sh` (root): bootstrap + build-engine `--skip-engine` + build + install — quick developer install.
- `installer/linux/install.sh` / `installer/macos/install.sh`: "managed" installation for end users (also uninstall).
- `scripts/icon_gen.py`: `png <svg> <out> <size>` and `iconset <svg> <dir>` (icons 16→512 + @2x) via `QSvgRenderer`, without creating a QApplication (so no platform plugin needed).
- See [ci.md](ci.md) for how the CI uses this pipeline with caching.
